# Frequently Asked Questions (FAQ)

### What is the primary purpose of HTML5 Modern Starter Boilerplate?
Clean semantic HTML5 starter boilerplate with accessibility scaffolding and modern responsive viewport configs.

### What technology stack is utilized?
HTML5, CSS3, JavaScript.

### How do I run this locally?
Clone the repository and serve the assets using a static HTTP server or run the development script according to `package.json`.
